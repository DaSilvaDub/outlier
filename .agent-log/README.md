# .agent-log — shared work journal

This folder is how every AI agent (claude, codex, grok, antigravity) tells the
others what it did. See the **Multi-Agent Sync Protocol** in the repo root
`AGENTS.md` for the full rules.

## What's in here

- `SUMMARY.md` — rolling snapshot: current state + open follow-ups. **Read this
  first.** Every agent overwrites it at the end of a session.
- `_TEMPLATE.md` — copy this to start a new session note.
- `YYYY-MM-DD-<agent>.md` — human-written session notes (the "why"). Add a
  `-2`, `-3` suffix if you write more than one on the same day.
- `YYYY-MM-DD-<agent>-<hash>.md` — auto-generated by the `post-commit` git hook,
  one per commit (the "what"). You don't write these by hand.

## Quick rules

- On start: read `SUMMARY.md` + the latest few entries here.
- On end: commit (hook logs it), write a session note, update `SUMMARY.md`.
- Never edit another agent's past entries. Append your own.
